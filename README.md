# Dashboard — Lade Studio Admin Dashboard

A sleek, single-file **admin dashboard** UI ("Lade Studio") built with plain HTML, Tailwind CSS (CDN), and vanilla JavaScript. A responsive dashboard template with sidebar navigation, stat cards, charts placeholders, and a modern dark-friendly design — no build step, no dependencies to install.

## ✨ Features

- **Single `index.html`** — the whole dashboard in one file
- **Sidebar navigation** with icons and active states
- **Stat cards / KPI widgets** with trend indicators
- **Responsive layout** — collapses gracefully on mobile
- **Tailwind CSS via CDN** — utility-first styling, zero build
- **Inter font** from Google Fonts, preloaded for speed

## 🛠 Tech Stack

- **HTML5** + **Tailwind CSS** (CDN) + **vanilla JavaScript**
- No framework, no build step

## 🚀 Quick Start

Just open `index.html` in a browser — or serve it:

```bash
npx serve .
# or
python3 -m http.server 8000
```

## 📁 Project Structure

```
Dashboard/
└── index.html   # the entire dashboard (markup + styles + scripts)
```

## 🌐 Deploy Notes

Static single-file site — deploys anywhere: **GitHub Pages**, Cloudflare Pages, Netlify Drop, or any static host.
